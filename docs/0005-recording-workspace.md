# 0005 — 多轨录制与项目恢复

状态：待验收。依赖：0002–0004。规格依据：[spec.md](spec.md)。进度入口：[progress.md](progress.md)。

## Task 整体描述

将原型整合为产品录制会话，加入摄像头、光标、标记、项目持久化与故障恢复。

## Task 具体实现逻辑

1. 实现 spec 中的录制状态机，启动时冻结 RecordingPlan、设备身份和 RunId；过期回调不允许修改新会话。
2. 摄像头用 Media Foundation 枚举/采集，独立写入源轨并记录首帧偏移；不使用预览镜像参数改写原始媒体。
3. 禁用 WGC 内嵌光标，用 Win32 位置/形状查询和鼠标事件记录光标；点击监听只采集所需事件，回调立即入队，不监听键盘文本。
4. 光标使用录制区域归一化坐标；窗口移动或 DPI 改变时同步更新几何映射。全局热键负责停止和标记，冲突可见。
5. 为录制栏和备忘录应用 capture exclusion 并实测，不把该 API 当作绝对防截图保证。
6. 创建 .frametrailproject 工作目录；源媒体按独立可完成分段写入，清单在分段完成后更新。结束时 flush 所有轨道、校验并保存工程。
7. 自动保存用 session epoch + revision + 串行队列，临时写入后同卷替换；保存 project.previous.json。关闭、移动、删除都等待屏障。
8. 重启扫描未正常结束的工程，仅恢复有效清单和可读分段；损坏末段单独提示。锁定同工程单写会话，缓存可重建。
9. 胶囊在录制前选择点击自动缩放，RecordingPlan 固定本次配置；分段完成时调用共享运镜规划器，保存效果及恢复快照。显示器/窗口使用箭头指针单击开始，区域保留十字拖框。
