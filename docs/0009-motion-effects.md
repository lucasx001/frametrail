# 0009 — 运镜与视觉包装

状态：已完成（本机 M3 功能验收）。依赖：0007–0008；其扩展验收仍保留原状态。规格依据：[spec.md](spec.md)。进度入口：[progress.md](progress.md)。

## Task 整体描述

补齐演示视频的差异化能力，在共享引擎中实现自动运镜和画面包装。

## Task 具体实现逻辑

1. 按参考 AutoZoomPlanner 规则实现点击分组、活动延长和相邻片段合并，确定缩放边界。自动生成保留来源标识，用户修改后不静默覆盖。
2. 实现手动缩放进入/保持/退出曲线、弹簧参数与光标平滑，所有采样由成片时间确定，不依赖预览帧率。
3. HLSL 实现屏幕透视、聚焦模糊、像素化/遮挡/柔化与合成遮罩；Direct2D/DirectWrite 生成必要静态图形。
4. 摄像头布局、出入场和屏幕开场动画共同进入 FrameScene；贴图/光标与屏幕的附着坐标关系明确。
5. 背景图片/循环视频、窗口/浏览器/设备框和预设以工程内资源引用保存，不依赖本机壁纸路径。
6. 为效果添加属性面板、时间线片段、复制粘贴与撤销；限制无效参数与效果越界。
7. 每新增一种效果同时增加预览/导出对比用例，组合效果重点检查图层顺序、alpha 和颜色。
