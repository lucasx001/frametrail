# 0023 — 共享摄像头实时预览

状态：待验收（本机 UVC 设备通过，外设/格式/拔插矩阵待验收）。依赖：0005。

## 范围与实现

- 录制条摄像头面板提供实时预览窗口和镜像开关。镜像只作用于此窗口；原始素材保持原方向，成片镜像在编辑器设置。
- 预览订阅与录制写入器使用同一个 Media Foundation 采集源；不创建第二个设备会话。
- 回调只保留最新不可变 sample；窗口按有界节奏读取 BGRA 帧，处理正/负 stride。切换、关闭及出错使用串行资源屏障。
- 预览窗口应用捕获排除。暂停/结束录制释放文件写入器；预览仍打开时摄像头继续采集，关闭最后一个订阅才释放设备。

## 验收

- [x] 本机 USB2.0 HD UVC WebCam，640×480、30 FPS 获得真实预览像素。
- [x] 预览与录制的 source identity 相同，录制有有效帧。
- [x] 停止文件写入后预览继续收到新帧。
- [x] 实际 WinUI 窗口显示连续帧、镜像切换与关闭释放。
- [ ] 29.97 FPS、其他分辨率、独占驱动/其他品牌、权限拒绝与真实拔插矩阵。
- [ ] 摄像头与桌面、系统音、麦克风的 30 分钟闪光/提示音联合同步。

证据与命令见 [P1 验证](validation/p1-editor-recording.md)。
