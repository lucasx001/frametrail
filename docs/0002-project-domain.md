# 0002 — 领域模型与时间线算法

状态：已完成。依赖：0001。规格依据：[spec.md](spec.md)。进度入口：[progress.md](progress.md)。

## Task 整体描述

把 DogSC 的领域设计转为独立的 FrameTrail 模型与可测试算法，为所有媒体和 UI 行为提供唯一语义。

## Task 具体实现逻辑

1. 定义 schema 1：媒体 manifest、源分段、轨道起点偏移、剪辑序列、效果、导出设置。时间采用整数 tick 与显式 timescale，转换时统一舍入规则。
2. C# ProjectWorkspace 保有权威项目快照；C++ 解析并校验不可变 revision 快照。编辑运算返回候选快照，App 原子提交；不允许两个层分别修改同一持久状态。
3. 移植 TimelineMap：源区间 → 成片区间，支持裁剪、重排、变速；拒绝重复 ID、无效区间、重叠源区间和空成片。
4. 明确半开区间、最终端点、切口两侧事件归属、取整和零时长策略；camera/audio/pointer 都使用同一映射。
5. 定义 FrameScene 与纯函数求值接口，先输出基础屏幕、背景与摄像头布局，不在本步实现 GPU。
6. 从参考 Swift 实现整理可人工核算的测试向量。无 Mac 环境时标记参考程序对照未完成，不伪造双平台执行结果。
7. 为未知未来 schema、非法相对路径、非有限数值、极端时长和外部 JSON 输入添加校验。
