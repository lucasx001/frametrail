# 0015 — 编辑器媒体准备与缓存

日期：2026-10-17。状态：待验收（实现及本机自动验证已接入）。依赖：0006–0008。

声音准备和缩略图使用独立媒体会话、取消源和任务。修改画面保留声音任务；修改声音不重建缩略图任务。按源文件身份、时间线及相关参数生成内容缓存标识，撤销和重开可复用波形与图片；声音预览使用流式混音，不再依赖整片 WAV。

- [x] 1 GiB 总字节目标与 400 文件限制，只清理 `cache/editor-*`。
- [x] 正在读写的缓存受保护；播放使用有界流式缓冲，不依赖完整磁盘混音。
- [x] 波形与缩略图通过临时文件完成后替换；取消清理未完成文件。
- [x] 波形侧缓存，缩略图最长 384×216，按可见区间替换排队需求。
- [ ] 长工程准备耗时、连续编辑的磁盘峰值与多小时资源稳定性验收。

2026-10-18：预览改为有界流式混音，波形准备显示进度；离线 PCM 支持 RF64。编辑器设置新增容量与清理入口。早期证据见 [编辑器优化](validation/editor-polish.md)，当前行为与 30/60/120 分钟逻辑工程验证见 [0024](0024-streaming-audio.md) 和 [P1 记录](validation/p1-editor-recording.md)。
