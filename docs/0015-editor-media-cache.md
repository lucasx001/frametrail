# 0015 — 编辑器媒体准备与缓存

日期：2026-10-17。状态：待验收（实现及本机自动验证已接入）。依赖：0006–0008。

声音准备和缩略图使用独立媒体会话、取消源和任务。修改画面保留声音任务；修改声音不重建缩略图任务。按源文件身份、时间线及相关参数生成内容缓存标识，撤销和重开可复用混音、波形与图片。

- [x] 1 GiB 总字节目标与 400 文件限制，只清理 `cache/editor-*`。
- [x] 正在读写/播放的混音受保护；单个活动混音可超过目标，不因清理中断播放。
- [x] 混音与缩略图通过临时文件完成后替换；取消清理未完成文件。
- [x] 波形侧缓存，缩略图最长 384×216，按可见区间替换排队需求。
- [ ] 长工程准备耗时、连续编辑的磁盘峰值与多小时资源稳定性验收。

完整混音仍使用 PCM RIFF WAV，单个混音超过约 4 GiB 时明确失败；尚未实现分块混音或 RF64。当前支持并行准备和内容复用，不宣称声音可以在混音完成前渐进播放。证据见 [本轮验证](validation/editor-polish.md)。
