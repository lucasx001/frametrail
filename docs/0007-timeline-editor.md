# 0007 — 时间线编辑与撤销重做

状态：待验收。依赖：0002、0005–0006。规格依据：[spec.md](spec.md)。进度入口：[progress.md](progress.md)。

## Task 整体描述

建立非破坏性编辑闭环，让主片段剪辑、辅助轨和效果具有统一可撤销命令。

## Task 具体实现逻辑

1. 将拖动、裁剪、分割、删除、重排、恢复、速率调整表示为 EditorCommand。C++ 领域层校验并产生新快照，C# 统一提交。
2. UI 维护选中项、播放头、工具与交互事务，持久项目只有一份。拖动预览与最终 commit 区分，取消恢复原快照。
3. 设计 Undo/Redo 命令历史，连续拖动合并一次；项目切换清空会话历史，避免旧对象引用。
4. TimelineMap 同步主画面、音频、摄像头、光标和源时间效果；新建效果明确锚定源时间还是输出时间，持久化标记其语义。
5. 实现虚拟化/按可见范围绘制时间线、吸附、缩放、播放头和逐帧步进；缩略图/波形异步生成并缓存。
6. 实现系统/麦克风全局与片段级音量和静音。确定并记录保持音调的时间伸缩实现及依赖许可。
7. 所有已提交编辑与撤销触发自动保存；保存失败可见但不丢弃内存编辑，允许重试。

## 实现边界

- Core 执行 split/trim/trimOutput/delete/move/rate/restore/settings/batch，保持源区间唯一且至少一个主片段；C# 只维护历史与交互，不重复时间映射。
- 拖动候选不保存；提交合并为一次命令，Esc 取消恢复原快照。撤销/重做保持内容并赋予更高 revision，同样自动保存；失败保留内存状态并可重试。
- 缩略图和波形在后台生成，时间线按可见范围与低密度聚合绘制；10,000 密集片段的实测见验证记录。
- 全局/片段音量与静音共用混音路径。原生 WSOLA 为自行实现，无新增第三方音频依赖；六档速率的音调/样本数检测通过，复杂语音/音乐人工听测仍待完成。
- 当前效果包络维持源时间锚定，剪辑不改写其参数；M3 高级效果尚未渲染。画布设置可复制/粘贴并撤销；包含高级效果的工程禁止成片导出，以免静默遗漏。
