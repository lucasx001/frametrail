# 导出按钮右侧裁切修复

日期：2026-10-16。

## 问题与修复

用户截图和实际编辑器均可复现：“选择位置并导出”按钮的右侧圆角在导出弹窗内被截平。原内容面板固定为 772 DIP，并按窗口宽度重新写入显式宽度；这绕过了 ContentDialog 模板内边距、边框及滚动视口的实际约束。

- 内容面板改为自动测量宽度，保留 772 DIP 上限；双栏使用比例星号列，跟随可用内容宽度。
- 底部改为填满可用宽度的 Grid，右侧两个操作按钮使用 Auto 列，保留按钮间距和完整圆角。
- 在模板的实际背景面板上设置首选宽度：普通窗口保持 820 DIP，较小窗口按根视图宽度扣除 96 DIP 余量收缩。内容仍由模板负责扣除内边距和边框。
- 不改变导出保存位置选择、编码参数、取消与完成流程。
