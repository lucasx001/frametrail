# 0024 — 流式声音预览与长音频

状态：待验收（本机实现、长工程启动与媒体回归通过；长时听测/资源矩阵待验收）。依赖：0004、0006–0008、0015。

## 范围与实现

- 预览从当前输出时间流式混音，保持现有双轨音量、剪辑与 WSOLA 保调规则，输出到有界 waveOut 缓冲；不等待整片 WAV。
- 播放时冻结工程快照，显示以实际音频采样位置为时钟；seek 重启到指定输出时间，暂停与退出回收设备和线程。
- 波形独立在后台准备，最多 24000 个峰值；显示准备百分比，失败仍可播放。预览选项提供显式静音播放。
- 导出/兼容 PCM 准备：小文件保留 RIFF，大于 4 GiB 使用 RF64/ds64；读取器识别实际 data 偏移，解除原约 6.2 小时输出上限。当前离线导出仍会生成临时 PCM，不声称已变为流式编码。
- 编辑器设置可选择 128–16384 MiB 缓存预算，清理当前工程的可重建缓存；保留正在使用的文件、源素材和非本产品缓存。

## 验收

- [x] 无 WAV/波形缓存时开始播放，音频时钟前进并可 seek。
- [x] 30/60/120 分钟逻辑工程不等待全片准备，直接定位尾部；内存和启动耗时有记录。
- [x] RIFF/RF64 头及 data 偏移验证；大尺寸头测试不生成 4 GiB 实体文件。
- [x] 混音、静音、音量及 0.25–4 倍速保调的独立音频验证。
- [x] 用户清理保留活动缓存、源素材与无关文件。
- [ ] 多小时持续听测、真实 >4 GiB 临时音频导出、跨声音设备与磁盘不足注入。
