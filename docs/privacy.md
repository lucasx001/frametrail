# 隐私与权限

FrameTrail 将录屏、音频、光标记录与工程编辑保存在本地。没有账户、云上传、AI 服务或遥测。请在开始前确认所选屏幕/窗口和音轨；摄像头与麦克风仅在选择并启用后使用。

光标事件用于工程内光标与运镜，不记录键入文本。录制画面和音轨会包含来源中实际出现的内容，请自行选择保存和分享位置。

应用崩溃诊断只保留版本、系统版本、异常类型、HRESULT 和不含文件路径的方法名。新诊断最多保留十份；不记录异常消息、命令行、用户名、完整工程、截图、设备序列号或媒体路径。旧版本生成的原始崩溃日志可能仍在本地，新版不会把它们加入诊断导出。

诊断信息仅在设置 → 关于 → 导出诊断信息时写到你选择的位置，不自动发送。开发验证脚本可能生成含本地路径的测试报告，分享前应自行检查。

检查更新会查询安装时配置的来源，可能向该来源提供正常网络请求信息，不发送工程内容。没有配置来源时不会连接项目预设服务器；本版本没有预设更新服务器。

工程放在安装目录之外。卸载便携版只需删除程序目录；MSIX 卸载可能清除包私有偏好和诊断数据，不应删除用户视频目录中的工程。升级、卸载和权限的跨机器验证状态见 M4 验收记录。
