# 0013 — H.265 与 AV1 编码支持

状态：待验收。依赖：0003、0006、0008。规格依据：[spec.md](spec.md)。

## 目的与实现

屏幕录制和最终 MP4 从固定 H.264 扩展为 H.264、H.265 / HEVC、AV1。保持 Windows 原生 WGC / D3D11 / Media Foundation 架构，共用现有合成、音频和文件事务逻辑。

1. 添加按格式探测的编码/解码 MFT 接口，以及显式指定 codec 的 capture 启动接口，保留旧 capture options/status 和默认启动 ABI。
2. 胶囊更多菜单提供录制编码，导出面板提供成片编码；不可用格式禁用并说明原因。录制需同时具备解码能力，保证工程可直接编辑。默认 H.264，选择写入工程并跨暂停/恢复保存。
3. 工程 JSON 和 C++ 权威校验一致接受 `h264/hevc/av1`。原始视频仍是 MP4，声音仍为 AAC，画面仍为 SDR BT.709 NV12。手机和摄像头的原始辅助路径保持既有编码。
4. 编码失败返回实际错误，不替换成其他编码；保留软件录制最高 1080p30、精确路径保护、临时文件清理和成片校验。

## 验收

- [x] 原生构建、7 组原生测试和 165 项托管测试通过
- [x] 三种格式的实际屏幕录制、暂停/续录、工程重开与首帧/中途 seek 通过
- [x] 三种格式 MP4 的独立编码标识、完整解码、帧数/时长、AAC 及画面比较通过
- [x] 胶囊与导出面板的真实 WinUI 编码选择、可用性及布局通过
- [x] 完成规格、使用指南和验证记录
- [x] 默认 Release 输出更新并启动新版
- [x] 三种编码 1080p/1440p/4K × 30/60 导出、4K 动画窗口录制短测及取消/目标占用保护
- [ ] 跨 GPU、缺失/故障驱动与长时录制矩阵

本机安装微软签名的 AV1 视频扩展 2.0.35.0 后完成 AV1 录后预览验证。完整硬件矩阵未测，保持待验收。

证据与复验命令见 [编码验证记录](validation/video-codecs.md)。

补充矩阵：18 组成片、12 组自身动画窗口录制全部独立解码通过。4K60 录制短测 H.264 59.66 FPS、HEVC 59.50 FPS、AV1 60.00 FPS，均确认硬件编码且队列丢帧为 0。每次捕获 3 秒，导出每种组合 0.5 秒；不作为长时或多显示器验收。
