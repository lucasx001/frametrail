# 0006 — 共享渲染与媒体预览

状态：待验收。依赖：0005。规格依据：[spec.md](spec.md)。进度入口：[progress.md](progress.md)。

## Task 整体描述

建立一套同时服务实时预览和离线导出的 GPU 合成器，并完成编辑器基础播放。

## Task 具体实现逻辑

1. 建立 D3D11 renderer 输入：FrameScene + 当前媒体纹理 + 固定颜色契约。先实现背景、屏幕、裁切、圆角、阴影、光标与摄像头。
2. 通过 SwapChainPanel 接入 WinUI，设置物理像素尺寸与 DPI 变化处理。选择框和手柄留在 UI 层。
3. Media Foundation 解码到 GPU 资源，明确 device manager 和纹理所有权；统一适配器选择，记录跨 GPU 回退。
4. PlaybackScheduler 根据输出时间查 TimelineMap，再驱动源 seek 和解码；从关键帧解码到目标帧，不能把 seek 返回位置直接当准确帧。
5. 播放时以稳定媒体时钟调度，暂停拖动用 generation 取消过期请求；预览降分辨率不改项目/导出参数。
6. 管理有界帧缓存、背景缓存、纹理池和 device lost；最小化时降低无意义渲染，恢复后强制提交有效画面。
7. 为图层合成创建固定时间截图测试，基础离屏渲染入口供后续导出复用。

## 实现边界

- MF 解码至 NV12，GPU 显式按 SDR 矩阵转 BGRA；FrameScene 在 Core 求值。屏幕/裁切/圆角/阴影/光标/摄像头由同一个 Renderer 合成，预览只降低栅格尺寸，不改项目参数。
- 预览使用音频设备样本时钟或 Stopwatch，按合成事件提交；generation 拒绝旧 seek。最小化暂停，恢复提交有效画面，重新加载可重建整个预览会话。
- 解码器/指针/图像缓存设上限；万片段时间线只绘制可见或聚合元素。关闭编辑器先取消缓存任务并释放 swap chain / reader，再返回录制条。
- 本机 1080p 原生合成吞吐与实际 WinUI 展示帧率分别记录；2026-10-15 修正预览帧槽调度后，1080p 窗口短测约 60 FPS，见 [连续性与性能记录](validation/capture-continuity-performance.md)。跨适配器、长时性能、真实 DPI 切换和 device lost 注入仍待验收。
