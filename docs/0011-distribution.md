# 0011 — 安装更新与发布准备

状态：待验收（2026-10-16，开发候选分发链路已实现；正式签名与安装/升级/卸载矩阵未完成）。依赖：0010。规格依据：[spec.md](spec.md)。进度入口：[progress.md](progress.md)。

## Task 整体描述

形成可在干净机器安装、更新和卸载的 Windows 产品交付物；实际对外发布为单独动作。

## Task 具体实现逻辑

1. 验证 MSIX + App Installer 路线的最低系统要求、包身份、原生依赖和 full-trust 桌面能力；记录最终发行方式及证书要求。
2. 开发测试签名与正式签名分开。无正式签名条件时只标记开发包，不宣称普通用户可无提示安装。
3. 安装包包含正确架构的原生 DLL、运行时与必要素材；不用开发机环境变量寻找依赖。
4. 测试安装、启动、录制、编辑、导出、卸载及升级；用户工程放在包安装目录之外，升级/卸载不擅自删除工程。
5. 定义更新检查、下载、验证、退出安装和失败提示；有未保存工作或活动媒体任务时不能自动终止应用。
6. CI 加入版本一致性、构建、测试、资源/依赖清单和产物校验，签名凭据通过 secret 管理。
7. 编写用户指南、权限说明、隐私说明、第三方许可和发布说明；明确当前未支持的设备与媒体格式。
8. 准备候选包与验收证据。本任务不自动购买证书、上传商店或对外发布，若另有明确发布指令再执行。
