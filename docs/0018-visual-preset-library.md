# 0018 — 场景预设管理

日期：2026-10-17。状态：待验收（实现及本机自动验证已接入）。依赖：0009、0015–0016。

用户预设位于 `%LOCALAPPDATA%/FrameTrail/Presets`，支持保存多个命名预设、重命名、删除、设为/取消录制默认、跨工程应用。每个预设携带其背景图片/视频，应用时复制回目标工程；工程不依赖预设库的后续存在。

- [x] 预设管理可从顶栏或紧凑窗口的项目菜单进入。
- [x] 新录制首个检查点应用默认预设，之后的分段保留该画面；失败提示并保留原始素材。
- [x] 应用走一次可撤销编辑，保留目标剪辑、效果和片段音量。
- [x] 原子保存、库级文件锁、损坏条目跳过并提示；最多 200 项、名称 1–60 字。
- [x] 保留旧版工程内单槽位预设读取/保存入口。
- [ ] 独立预设包导入/导出、缩略图式预设库及更大资源集合的体验验证。

画布、静态画面/光标和全局音量随预设保存；按片段 ID 的音量与带时间范围的动效保留在目标工程。证据见 [本轮验证](validation/editor-polish.md)。
