# 0008 — 离线导出闭环

状态：待验收。依赖：0006–0007。规格依据：[spec.md](spec.md)。进度入口：[progress.md](progress.md)。

## Task 整体描述

将当前项目完整导出为 MP4 或音频文件，验证预览与成片一致性和文件安全。

## Task 具体实现逻辑

1. 导出开始固定项目 revision，验证媒体引用、范围和输出能力，先完成持久化 flush，再禁止该工程编辑。
2. 使用有理时间输出帧计划，按帧号调用 TimelineMap 与 FrameSceneEvaluator；读取对应源帧并交给任务 0006 的共同渲染器。
3. 渲染到离屏纹理后转换为编码器支持的像素格式，例如 NV12；明确颜色空间和范围，尽可能使用 GPU 路径。
4. 音频独立按成片时间线混合、变速、音量和静音处理，转 AAC；样本计数决定结束位置，处理最后一帧/尾部音频舍入。
5. 实现 H.264 / H.265 / AV1 + AAC MP4、M4A 与源素材复制导出；1080p/1440p/4K、30/60 组合运行时检查，编码扩展见 [0013](0013-video-codecs.md)。
6. 临时文件写在目标旁，成功 finalize 并校验后替换；失败/取消释放 reader/writer/GPU 资源并清理本任务临时文件。
7. 阶段进度来自实际输出帧和音频进度，watchdog 检测无进展；磁盘不足、目标占用、编码器失败均返回可恢复错误。

## 实现边界

- 导出固定修订并等待保存屏障，期间禁止同工程编辑；源媒体仍不可变。帧号和样本号决定输出时间，未使用实时定时器推进离线导出。
- 共用 Renderer 在 GPU 合成并转 BT.709 limited-range NV12，目前通过有界 CPU readback 输入 MF writer；不把启用硬件 transform 选项当作硬件编码证明。
- 成功 finalize 且 MF 校验通过后同卷替换目标；取消、目标占用已实际验证，磁盘不足的异常分支已实现但尚未注入实测，因此该整项保留未勾选。
- 1080p/1440p/4K × 30/60 均完成 0.2 秒能力短测；长时吞吐、驱动故障与硬件编码确认留待后续矩阵。PCM 混音缓存超过 RIFF 4 GiB 会明确报错。
