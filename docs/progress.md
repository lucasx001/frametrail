## 状态与更新规则

状态只能使用：未开始、进行中、待验收、已完成、阻塞。阻塞时必须记录原因和解除条件。

1. 开始任务时记录日期、范围和当前状态。
2. 完成代码后勾选对应任务中的实现项；只有拿到验收证据才勾选验收项。
3. 将构建、自动测试、实机测试分别记录，不用“编译通过”代替功能通过。
4. 需求或技术路线改变时同步更新 spec 与对应任务，说明影响范围。
5. 每个任务完成时在下方追加摘要；详细日志保存到 `docs/validation/`，只保存脱敏材料。
