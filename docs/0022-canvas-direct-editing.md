# 0022 — 画布直接编辑

状态：待验收（本机实现与自动验证完成，扩展 DPI/实际手势矩阵待验收）。依赖：0006–0009、0014。

## 范围与实现

- 原生渲染器和编辑器几何共用 `plane_projection.hpp`，返回归一化四边形与附件平面。应用只做命中坐标的逆变换，不重复实现场景或时间求值。
- 支持裁切框、贴图、遮挡与聚焦区域的选中、移动和四角缩放；透视、旋转、预览倍率与全屏均使用当前画面的坐标。
- 裁切模式显示完整原始画面，暂时收起包装与运镜；再次点击裁切或 Esc 返回成片预览，工程中的效果与摄像头设置仍保留。
- 拖动过程实时预览，松手提交一次事务；Esc/指针取消恢复原状态。关闭、切换与导出等待事务收束。
