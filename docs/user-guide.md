# FrameTrail 使用指南

适用版本：0.4.0 开发候选版。Windows 11 x64，最低 build 22621；当前验证机器为 build 26300。

## 安装与启动

便携包：解压到有写入权限的目录，运行 `FrameTrail.App.exe`。包内包含 .NET、Windows App SDK 和原生引擎，不需要安装开发工具。不要直接从 ZIP 内启动。

MSIX：只有带可信签名的包才能按正常侧载流程安装。当前未签名候选包仅用于打包验证，不能当作普通用户安装包。开发证书只用于测试，必须先核对发布者和证书来源；本项目的打包脚本不会导入信任证书。

## 录制与剪辑

1. 在悬浮条选择显示器、窗口或区域，分别开启需要的系统声音、麦克风和摄像头。显示器和窗口使用普通指针，单击目标即可开始；区域使用十字光标，拖框后确认开始。
2. 在更多菜单选择视频编码（H.264、H.265 / HEVC 或 AV1），并检查帧率与保存位置。不可用编码会灰显并提示原因。录制时可暂停、继续、添加标记；快捷键以菜单显示的当前组合为准，注册冲突会提示。
3. 停止录制后打开编辑器。空格播放/暂停，左右键逐帧，S 分割，Ctrl+Z / Ctrl+Y 撤销/重做，Esc 取消拖动。
4. 调整剪辑、声音、背景及运镜后导出 MP4，或单独导出 M4A；素材副本可保留独立文件。导出面板可选择 H.264、H.265 / HEVC 或 AV1，声音为 AAC；编码选择随工程保存。

编辑自动保存。显示“未保存”时请点击重试并保持窗口打开；关闭前保存失败会保留内存编辑。导出期间请等待完成或取消后再关闭。

备忘录：从录制胶囊打开后，将鼠标移到顶部「备忘录」标题及其空白区，会显示四向移动指针；按住左键可拖动窗口。正文保留输入、选择和滚动，右侧按钮可切换阅读 / 编辑及调整字号。点击收起、再次点击胶囊备忘录按钮或退出应用时会先保存；保存失败会保留窗口并提示重试。

视频区播放控件右侧的「全屏预览」按钮、F11 或双击视频可进入全屏；按 Esc、F11、再次双击视频或点击「退出全屏」返回。全屏保留播放 / 暂停、左右逐帧和时间显示，视频按画布比例完整适配屏幕。退出后恢复窗口、检查器、时间线及原来的预览缩放。

编辑器默认使用「4K · 高清预览（默认）」，普通窗口和全屏均在 3840×2160 范围内渲染，竖屏对应 2160×3840，保持画布比例，再以高质量采样缩小到预览区。样机边框、网址和文字随分辨率重绘；低分辨率原视频的细节仍受素材限制。如需降低显卡负载，可在播放控件中的「预览选项」→「预览清晰度」选择「自动 · 匹配屏幕」，按显示区域的物理像素重绘（最高 4K）。该选项只作用于预览，不改变工程、导出尺寸或录制分辨率；重新加载预览会保留当前选择，新打开的编辑器默认使用 4K。

编码可用性取决于显卡驱动和 Windows 视频扩展。AV1 录后预览需要系统 AV1 解码器，缺少时可安装微软官方 [AV1 视频扩展](https://apps.microsoft.com/detail/9mvzqvxjbq9v)，安装后刷新来源与设备或重启应用。没有 AV1 解码器时仍可把已有的其他编码工程导出为 AV1。软件录制需勾选允许软件编码，最高 1080p30；手机原始录制使用 H.264，成片导出时可选其他编码。

录制前可点击胶囊上的「点击自动缩放」图标切换，默认开启，图标下方绿点表示已开启。点击后画面平滑放大，连续操作保持聚焦，停止操作后缩回全景。关闭后仍保留光标与点击记录，本次录制不会自动生成运镜；关闭「记录光标与点击」或切换 Android 时，该功能不可用。

自动缩放随分段、暂停和停止保存到工程，录完打开编辑器即可查看，无需手动生成；已有片段仍能调整、删除或撤销。原始素材保持全景，缩放效果出现在编辑器预览和导出的成片中。

画面 → 样机：拖动卡片、点击两侧卡片或圆形箭头，选择无边框、浅 / 深色 macOS 窗口、浅 / 深色浏览器或自适应设备框。转盘获得焦点后可用左右键切换。窗口标题与浏览器网址会进入预览和成片，切换样式后仍保留。

旋转或滚动旋钮调整框体比例、顶栏高度及外圆角；设备框有比例和外圆角两项。Shift 拖动 / 滚动可精调，点击数字可直接输入，Esc 取消当前编辑。每次拖动、滚轮操作或文字编辑会合并为一次撤销。「还原样式」恢复当前样式的默认外观，保留标题和网址。

光标检查器可选择录制时的指针、箭头、圆点和十字，设置点击波纹/高亮的颜色、大小与不透明度，或启用静止隐藏。时间校准的正值让光标提前，负值让光标延后；原始录制事件不变。这些设置随工程保存，并进入导出视频。

顶栏「场景预设 → 管理场景预设…」可保存多个命名预设，重命名、删除、设为录制默认或应用到当前工程。紧凑窗口可从「项目 → 场景预设…」进入。预设背景会随保存/应用分别复制；删除预设不会删除已应用工程的背景。设为默认只影响之后的新录制，打开已有工程不会自动覆盖画面。应用预设可撤销，原有剪辑、运镜片段及片段音量保留。

时间线胶片按可见时间连续取帧，滚动和缩放时后台补充。声音从播放头流式混音，不必等待完整缓存。波形与缩略图独立在后台准备，音量或剪辑改变后更新波形，撤销可以复用已有结果。设置 → 编辑器可调整缓存容量和清理当前工程缓存；源素材与活动文件保留。导出临时音频自动选择 RIFF 或 RF64。

## 工程、恢复与权限

点击录制准备胶囊上的文件夹按钮「打开已有项目」，会直接显示应用内项目列表。列表按最近保存时间排序，显示名称、录制时长、画布尺寸和位置；可以搜索名称或位置，点击项目行直接进入编辑器。默认列出保存目录中的项目，也会记住从其他位置打开的项目；「其他位置…」可添加一个项目所在文件夹，不需要寻找内部的 `project.json`。修改录制保存文件夹后，会记住新位置并保留之前的项目位置。

编辑器左上角「项目」菜单 →「切换项目…」打开同一个项目列表，同时列出当前项目父目录中的其他项目。切换会保存当前修改，取消或打开失败会保留当前项目。搜索后只有一个可打开的结果时，可按 Enter 打开；Esc 关闭列表。

删除：项目列表每行右侧有独立的删除按钮，点击不会打开该项目。确认框展示名称和完整路径，默认「取消」；点击「移到回收站」后删除所选项目及其录制素材，并刷新列表。删除当前项目会先保存并释放编辑器；其他项目的删除不影响当前编辑。损坏或未完成的项目仍可在列表中清理，被其他会话占用时会拒绝删除。编辑器右上角原有的「删除项目」入口保留。位置不支持回收站时，Windows 会再询问是否永久删除；录制或导出中不能删除当前项目。

分割、裁切、运镜和样机边框等编辑直接更新已有预览，保持当前画面、后台替换缩略图；无需整页重新加载。剪辑或声音变化后会后台更新波形，有声播放可立即开始；预览选项也提供静音预览。

默认工程位于用户“视频”目录下的 `FrameTrail`，每个 `.frametrailproject` 是包含原媒体的目录。移动时请复制整个目录。不要把工程存到程序安装目录。

中断后可从恢复入口选择工程。恢复只接受完整可读的分段和有效快照；未完成的尾段保留在磁盘上，不保证修复。工程 JSON 损坏可回退到上一份有效保存；新版 schema 必须使用兼容版本打开。

设备无画面或无声音时，先检查 Windows 设置中的摄像头/麦克风隐私权限、默认声音设备以及设备是否被其他程序占用。受保护内容不保证可录制。

## 更新与卸载

设置 → 关于 → 检查更新只查询安装来源，不安装或结束应用。开发版没有默认更新服务器。发现新版后先停止录制/导出，确认工程已保存并退出全部窗口，再从原安装来源安装。不要使用强制结束进程的安装参数。

MSIX 通过 Windows“已安装的应用”卸载；便携版退出后删除解压目录。用户放在安装目录外的工程不由卸载器删除。MSIX 的应用私有偏好/诊断数据可能被系统清除，卸载前可主动导出需要的诊断信息。

## 当前范围

支持 SDR Windows 桌面来源及工程内置效果；Android USB 实现已合入，连接与验收范围见 [0012](0012-android-usb-recording.md)，真机、ROM/驱动和长时同步仍待验收。HDR 当前显式拒绝录制；4K60 已有本机短测，复杂效果 1080p60、多 GPU/多 DPI、锁屏/睡眠及长时音画同步尚未全面验收。中文界面已实现，英文界面尚未完成。

## 画布直接编辑与摄像头预览

点击预览下方“裁切”，在完整原始画面上拖动角点或移动选框；再次点击或按 Esc 返回成片。贴图、遮挡和聚焦区域可直接在画布选中、移动和缩放。松手保存为一次撤销，拖动中按 Esc 取消。

录制条的摄像头面板可打开实时预览。镜像开关仅影响预览窗口；原始素材保持原方向，成片可在编辑器中另设镜像。预览与录制共享采集源，结束录制后预览仍可继续；关闭最后一个使用该设备的窗口/录制会话后才释放摄像头。
