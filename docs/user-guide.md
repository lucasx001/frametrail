# FrameTrail 使用指南

适用版本：0.4.0 开发候选版。Windows 11 x64，最低 build 22621；当前验证机器为 build 26300。

## 安装与启动

便携包：解压到有写入权限的目录，运行 `FrameTrail.App.exe`。包内包含 .NET、Windows App SDK 和原生引擎，不需要安装开发工具。不要直接从 ZIP 内启动。

MSIX：只有带可信签名的包才能按正常侧载流程安装。当前未签名候选包仅用于打包验证，不能当作普通用户安装包。开发证书只用于测试，必须先核对发布者和证书来源；本项目的打包脚本不会导入信任证书。

## 录制与剪辑

1. 在悬浮条选择显示器、窗口或区域，分别开启需要的系统声音、麦克风和摄像头。显示器和窗口使用普通指针，单击目标即可开始；区域使用十字光标，拖框后确认开始。
2. 在更多菜单选择视频编码（H.264、H.265 / HEVC 或 AV1），并检查帧率与保存位置。不可用编码会灰显并提示原因。录制时可暂停、继续、添加标记；快捷键以菜单显示的当前组合为准，注册冲突会提示。
3. 停止录制后打开编辑器。空格播放/暂停，左右键逐帧，S 分割，Ctrl+Z / Ctrl+Y 撤销/重做，Esc 取消拖动。
4. 调整剪辑、声音、背景及运镜后导出 MP4，或单独导出 M4A；素材副本可保留独立文件。导出面板可选择 H.264、H.265 / HEVC 或 AV1，声音为 AAC；编码选择随工程保存。

编辑自动保存。显示“未保存”时请点击重试并保持窗口打开；关闭前保存失败会保留内存编辑。导出期间请等待完成或取消后再关闭。

编码可用性取决于显卡驱动和 Windows 视频扩展。AV1 录后预览需要系统 AV1 解码器，缺少时可安装微软官方 [AV1 视频扩展](https://apps.microsoft.com/detail/9mvzqvxjbq9v)，安装后刷新来源与设备或重启应用。没有 AV1 解码器时仍可把已有的其他编码工程导出为 AV1。软件录制需勾选允许软件编码，最高 1080p30；手机原始录制使用 H.264，成片导出时可选其他编码。

录制前可点击胶囊上的「点击自动缩放」图标切换，默认开启，图标下方绿点表示已开启。点击后画面平滑放大，连续操作保持聚焦，停止操作后缩回全景。关闭后仍保留光标与点击记录，本次录制不会自动生成运镜；关闭「记录光标与点击」或切换 Android 时，该功能不可用。

自动缩放随分段、暂停和停止保存到工程，录完打开编辑器即可查看，无需手动生成；已有片段仍能调整、删除或撤销。原始素材保持全景，缩放效果出现在编辑器预览和导出的成片中。

画面 → 样机：拖动卡片、点击两侧卡片或圆形箭头，选择无边框、浅 / 深色 macOS 窗口、浅 / 深色浏览器或自适应设备框。转盘获得焦点后可用左右键切换。窗口标题与浏览器网址会进入预览和成片，切换样式后仍保留。

旋转或滚动旋钮调整框体比例、顶栏高度及外圆角；设备框有比例和外圆角两项。Shift 拖动 / 滚动可精调，点击数字可直接输入，Esc 取消当前编辑。每次拖动、滚轮操作或文字编辑会合并为一次撤销。「还原样式」恢复当前样式的默认外观，保留标题和网址。

## 工程、恢复与权限

点击录制准备胶囊上的文件夹按钮「打开已有项目」，会直接定位到项目保存目录，选择一个 `.frametrailproject` 文件夹即可打开。修改「保存文件夹」后会记住新位置，下次启动仍使用该位置。

编辑器左上角「项目」菜单 →「切换项目…」可选择另一个本地项目，选择器先显示当前项目的父目录。切换会保存当前修改，取消选择或打开失败会保留当前项目。

删除：打开项目后，点击编辑器右上角「删除项目」。确认框展示项目名称和完整路径，点击「取消」继续编辑；点击「确认删除」后保存并关闭当前项目，移入回收站，再返回录制胶囊。位置不支持回收站时，Windows 会再询问是否永久删除。正在录制或导出时不能删除。胶囊不再提供删除入口。

分割、裁切、运镜和样机边框等编辑直接更新已有预览，保持当前画面、后台替换缩略图；无需整页重新加载。剪辑或声音变化后会重新准备声音缓存，完成后即可有声播放。

默认工程位于用户“视频”目录下的 `FrameTrail`，每个 `.frametrailproject` 是包含原媒体的目录。移动时请复制整个目录。不要把工程存到程序安装目录。

中断后可从恢复入口选择工程。恢复只接受完整可读的分段和有效快照；未完成的尾段保留在磁盘上，不保证修复。工程 JSON 损坏可回退到上一份有效保存；新版 schema 必须使用兼容版本打开。

设备无画面或无声音时，先检查 Windows 设置中的摄像头/麦克风隐私权限、默认声音设备以及设备是否被其他程序占用。受保护内容不保证可录制。

## 更新与卸载

设置 → 关于 → 检查更新只查询安装来源，不安装或结束应用。开发版没有默认更新服务器。发现新版后先停止录制/导出，确认工程已保存并退出全部窗口，再从原安装来源安装。不要使用强制结束进程的安装参数。

MSIX 通过 Windows“已安装的应用”卸载；便携版退出后删除解压目录。用户放在安装目录外的工程不由卸载器删除。MSIX 的应用私有偏好/诊断数据可能被系统清除，卸载前可主动导出需要的诊断信息。

## 当前范围

支持 SDR Windows 桌面来源及工程内置效果。当前分支基于 main，未包含独立 M5 分支的 Android USB 实现。HDR、4K60、复杂效果 1080p60、多 GPU/多 DPI、锁屏/睡眠及长时音画同步尚未全面验收。中文界面已实现，英文界面尚未完成。
