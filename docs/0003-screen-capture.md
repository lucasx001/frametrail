# 0003 — 屏幕采集与编码原型

状态：待验收。依赖：0001–0002。规格依据：[spec.md](spec.md)。进度入口：[progress.md](progress.md)。

## Task 整体描述

先验证 Windows 原生采集到可播放视频的最小媒体链路，建立可量化性能基线。

## Task 具体实现逻辑

1. 枚举/选择窗口和显示器，使用 Windows.Graphics.Capture 创建 D3D11 帧池；捕获操作在用户明确选择后启动。
2. 区域录制限定单显示器，将 DIP 选择矩形转为物理像素裁切区；声明 Per-Monitor DPI Awareness V2。
3. 采用后台帧回调、有界队列和自有纹理池。归还捕获帧前完成自有资源拷贝，不异步使用已失效表面。
4. 保存真实帧时间戳，处理静态画面少回调与动态画面高频回调；编码节奏策略与输入帧计数分开统计。
5. 使用 Media Foundation 写 H.264 MP4，探测可用硬件 MFT；失败时提供受限软件模式或明确错误，不无限重试。
6. 探测尺寸变化、主窗口关闭、GPU device removed、HDR 输入；HDR tone mapping 尚未验收时阻止该路径并提示。
7. 记录基线设备、驱动、系统版本与动态测试素材；提供采集帧数、写入帧数、丢帧、CPU/GPU 和队列指标。
