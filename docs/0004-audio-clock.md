# 0004 — 音频采集与时钟同步

状态：待验收。依赖：0003。规格依据：[spec.md](spec.md)。进度入口：[progress.md](progress.md)。

## Task 整体描述

实现系统音、应用音与麦克风独立采集，并建立统一时间轴和暂停协议。

## Task 具体实现逻辑

1. WASAPI shared-mode 捕获选定输出设备 loopback 与麦克风；支持 Application Loopback 进程树模式并检测 API 可用性。
2. 明确窗口到 PID/进程树映射，UI 提示应用音范围；浏览器标签页不承诺单独隔离。
3. 保存设备原始时间、采样位置和 QPC 对应关系；以首个有效主视频帧为零点处理音频前导和启动延迟。
4. 内部音频处理格式统一为浮点 PCM，输出混音约定 48kHz；设备格式转换、声道映射和重采样必须显式。
5. 录制暂停/恢复使用同一会话偏移，跨暂停音频缓冲裁剪而非直接拼接时间戳。建立漂移指标与必要的受控修正。
6. 系统音和麦克风保留独立源轨，最终成片再混合；音频电平更新节流，不能每个 buffer 重绘全部 UI。
7. 切换默认设备、拔掉麦克风或无音频时返回可解释状态；不把合法静音判成失败。
