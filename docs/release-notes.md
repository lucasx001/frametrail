# 0.4.0 开发候选版

2026-10-19：新增 OpenScreen 同款 18 张桌面壁纸，可在「画面 → 背景 → 壁纸」直接选择，也可导入自己的图片。选中壁纸随工程保存，支持撤销 / 重做；大图按预算解码，预览和导出使用同一背景。

M0–M3 已形成录制、编辑与导出闭环，包含 M4 可靠性/分发准备和 M5 Android USB 的本地实现。实际可发布范围以 [当前进度](progress.md) 为准。

2026-10-19：修复首次使用说明被录制胶囊裁切、无法看到退出按钮的问题；说明改为独立窗口，底部操作始终可见，支持关闭与 Esc 返回录制条。

2026-10-18 P1/P2：画布直接编辑、共享摄像头预览、流式声音/RF64/缓存管理；时间线悬停与属性粘贴、虚拟列表/区间索引、GPU 表面导出兼容回退、官方更新检查、中英文与首次使用/键盘可访问性。详见 [P1](validation/p1-editor-recording.md)、[P2](validation/p2-workflow-performance.md)。

2026-10-17 编辑器改进：声音与缩略图独立准备、按内容复用和按容量清理缓存；连续多帧时间线胶片；光标样式、点击反馈、静止隐藏和时间校准；跨工程命名预设库、资源复制与新录制默认预设。详见 [验证记录](validation/editor-polish.md)。

2026-10-17 分发改进：新增 GitHub Release 自动工作流，支持手动版本号或 tag，提供每用户 Setup.exe、自包含便携 ZIP、安装说明及 SHA-256。安装器未签名，应用运行期间拒绝安装/卸载；更新从 Releases 手动下载。首次公开版本和实测状态见 [发布验证](validation/github-releases.md)。

Microsoft Store 分发补充：提供独立 MSIX 提交包、商店身份配置和专用工作流；认证后由 Microsoft 签名，无需购买代码签名证书。当前尚未注册应用，先提供测试身份包，正式身份、安装和认证另行验收，见 [Store 说明](microsoft-store.md)。

- 恢复清单缺失或损坏时检查保存快照；拒绝用旧检查点覆盖未来 schema 工程。
- 崩溃诊断脱敏并限制保留数量，可主动导出；关于页提供版本、文档与只查询不安装的更新入口。
- 提供 x64 自包含便携 ZIP、MSIX 候选包、文件依赖清单与 SHA-256 校验；可选已有证书签名和 HTTPS App Installer 描述文件。
- 提供独立视频录制性能/资源/解码验证命令；音画同步与硬件矩阵仍需独立验收。

本轮开发候选版尚未正式发布。未签名 MSIX 无法按正常侧载安装。正式签名、干净机器安装/升级/卸载、30 分钟联合音画同步与跨硬件验收尚未完成；中英文已接入，完整可访问性人工矩阵仍待验收。详细状态见 `docs/validation/m4-reliability-distribution.md`。
